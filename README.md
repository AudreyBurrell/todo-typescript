# Todo List
A web application designed so users can keep track of their tasks. Each task has a priority (high, medium, or low) assigned to it, which is displayed with the task as well as the due date (due today, overdue, upcoming). 

I got this idea because I decided that I wanted to learn how to use TypeScript with React and also to learn how to do testing. I have made a project very similar to this (Assignment Tracker, [view here](https://github.com/AudreyBurrell/Semester-to-do-list)) so I could be less focused on figuring out the functionality and instead focused on learning TypeScript, Vitest, and React Testing Library. 

## Features 
* **Add Assignments** - Create assignments with names, due dates, and priority. The user can do this either one at a time using the Add Task feature or by uploading a CSV.
* **Filter Assignments** - Users can search using assignment names, due dates (due today, upcoming, or overdue), and priority. 
* **Check Off Completed Work** - Mark assignments as complete/incomplete
* **Progress Tracking** - Users can see the percentage of assignments they have done
